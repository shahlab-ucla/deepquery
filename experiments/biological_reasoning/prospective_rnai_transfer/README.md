# Prospective RNAi transfer

Question: can a prediction frozen before outcome collection transfer to new perturbations or
genetic backgrounds?

The experiment defines preregistration, blinded-result locking, limited adaptation,
outcome-access accounting, and interpretation contracts. Selection and thresholds cannot
change after results are opened.

Status: contract behavior is tested synthetically; no real prospective experiment has been
executed.

Implementation: `wormctx.poc.prospective_transfer`.
