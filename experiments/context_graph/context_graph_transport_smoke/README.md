# Context graph and transport smoke

Question: can a committed, rights-safe observation fixture be transformed into the faithful
context graph, loss-aware exchange projection, and query-specific transport map through the
same provider-neutral execution layer used for larger experiments?

The execution manifest binds the observation fixture, query context, and transport policy by
SHA-256. It declares the complete demo directory as its output and therefore receives a
recursive checksum closure in the execution receipt.

Status: executable packaging and portability control. It tests graph construction,
transport scoring, build-receipt verification, and execution mechanics; it is not a
biological-result lane.
