# Lineage-topology ablation

Question: does authentic cell-lineage topology add predictive information beyond semantic
identity, stage, depth, and model capacity?

Controls include authentic edges, no edges, matched depth/stage structure, and deterministic
degree/depth-preserving rewired trees. Topology is frozen before outcomes are opened.

Status: model variants, topology validation, rewiring, and synthetic tests are implemented.
No real topology-performance claim is made.

Implementation: `wormctx.poc.developmental_topology`.
