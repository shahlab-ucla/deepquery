# Pilot early-to-late prediction

Question: can early embryo measurements predict later outcomes for perturbation genes excluded
from fitting?

The pilot compares a constant predictor, target-blind flat ridge, semantic-cell ridge, and
negative controls. Whole embryos remain indivisible and perturbation identity is not a model
feature.

Status: the controlled-source pilot completed technically. Early flat features showed signal,
while the first semantic-lineage representation did not improve on the flat baseline. This is
model-design evidence, not a developmental mechanism.

Implementation: `wormctx.poc.developmental_omix`.
