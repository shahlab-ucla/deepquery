# Pangenome-state qualification

Question: are genuine regional state calls, relationships, coordinates, and population groups
sufficiently qualified for state-aware association?

The gate rejects substitution of ordinary SNP profiles or divergent-region annotations for
explicit state calls. It also verifies carrier counts, missingness, sample order, kernels, and
upstream null interpretation.

Status: interfaces and synthetic gates qualified; real execution remains blocked on genuine
state-call receipts.

Implementation: `wormctx.poc.qtl_haplotype_pav` and
`qtl_regional_state_prediction_gates`.
